# Requirements

| ID | Feature | Acceptance criterion |
| --- | --- | --- |
| F-01 | See available rooms | When I pick a date, I can see which 30-minute slots are free for each room. |
| F-02 | Reserve a slot | Two simultaneous requests for the same room and slot yield one booking and one conflict. The second person can choose another slot. |
| F-03 | Cancel your booking | The person who reserved the slot can cancel it. Once cancelled, it appears as available again. |
| F-04 | Sync to Google Calendar | Parked for a later release. |
