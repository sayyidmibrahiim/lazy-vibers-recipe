# Futsal booking example

This example reproduces the plan from a recorded rehearsal. Contact details, machine paths, and project addresses use example values. The stack, prices, and progress reflect the rehearsal's records. The journal, interview notes, and proposed Futsal app labels preserve the rehearsal's original language.

To view it, start the Recipe dashboard and enter `examples/futsal-booking` in **Open Local LVR Folder**. The project contains the plan, replayable state, and its history.
