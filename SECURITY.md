# Security policy

Report suspected vulnerabilities privately through the repository's [security advisory form](https://github.com/sayyidmibrahiim/lazy-vibers-recipe/security/advisories/new) when it is available. If needed, ask the maintainer for a private reporting channel before sharing details.

Include the affected commit or release, operating system, Node.js version, the affected component, and a minimal description of the observed impact. Sanitize project paths, journal contents, and credentials. Use a disposable project when testing a report.

The dashboard is designed for local use. Store the legacy generator's provider credentials in an ignored `.env.local` file. Run or publish verification data from sanitized examples. [Local setup](README.md#production-build-and-legacy-generator)
