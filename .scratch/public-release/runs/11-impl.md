# Ticket 11 implementation

The data module records an evidence-bearing stores_data flag for any product type. Eight questions connect S2, S3 and S4 answers to the storage decision and schema. S6 applies the schema designer and checks a selected vendor only after the owner's decision. S9 writes the model and corresponding access/privacy checks.

The module ships one copy of its storage and schema guide with the init skill. Lint allows an erDiagram in SPEC/data-model.md and keeps the existing error format for other Mermaid fences. Four pinned vendor and schema references were added, gated by data and selected-vendor flags.
