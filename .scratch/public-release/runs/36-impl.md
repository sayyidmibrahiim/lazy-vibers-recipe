# Ticket 36 implementation

The lifecycle assigns cleanup to handoff unless the recorded next step is a Recipe build. Build then owns the initial cleanup after verification. Later add-feature, review and brand runs can reinstall applicable aids, then use their journal window for cleanup. Continue can resume an unfinished consent prompt. `booster cleanup` optionally bounds current owned receipts by journal sequence and respects recorded keep decisions for that closure. Exact-path approval, state replay, content hashing and ownership protections still apply.
